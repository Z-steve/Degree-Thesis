About SDS

The DNS-Based Intrusion Detection System

The DNS-Based Intrusion Detection System (SDS) monitors network traffic to detect and block malicious activities, such as unauthorized network scans or reverse lookups from compromised internal machines.

By forcing an aggressively short Time-To-Live (TTL) on DNS responses, the SDS effectively nullifies "cache evasion" tactics used by stealthy network worms and scanners. It maintains a stateful DNS expiration table, mapping internal IPs to recently resolved external IPs.

Any outbound connection attempt that lacks a corresponding, unexpired entry in this table is immediately flagged as an unauthorized scan. The system dynamically blocks offending IPs while ensuring that legitimate, pre-allowlisted traffic continues unimpeded.

This web interface provides administrators with real-time visualization of network topology, blocked IPs, system performance metrics, and tools to execute administrative commands instantly.
