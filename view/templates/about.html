DNS-BASED IDS

The DNS-Based Intrusion Detection System (IDS) monitors network traffic to detect and block malicious activities, such as unauthorized network scans or reverse lookups. It maintains a DNS expiration table, blocks offending IPs, and allows legitimate traffic. The web interface visualizes network topology, manages blocked IPs, and supports administrative commands.
